# ForTravel - 世界地图游记应用开发计划

## 📋 需求分析

### 核心功能
- **世界地图背景**：交互式世界地图
- **图钉管理**：标记去过的国家
- **照片展示**：点击图钉查看合照
- **地点搜索**：在地图上搜索并创建图钉
- **图片上传**：支持 jpeg/jpg/png 格式，不限制大小

---

## 🎯 技术栈选择

### 前端框架
**Vue 3**（最新稳定版）

### 地图组件方案对比

| 方案 | 组件 | 免费 | 功能 | 推荐度 |
|------|------|------|------|--------|
| **方案 A** | Leaflet + OpenStreetMap | ✅ 完全免费 | 完整功能 | ⭐⭐⭐⭐⭐ |
| **方案 B** | Mapbox GL JS | ❌ 需要 API key | 优秀性能 | ⭐⭐⭐ |
| **方案 C** | Google Maps | ❌ 付费 | 优秀体验 | ⭐⭐ |

### 推荐：方案 A（Leaflet + OpenStreetMap）

**原因**：
- ✅ 完全免费，无需 API key
- ✅ 功能完整（标记、弹出窗口、路线等）
- ✅ 社区活跃，插件丰富
- ✅ 轻量级，适合世界地图
- ✅ 支持自定义样式和标记

## 🎨 核心功能设计

### 1. 世界地图组件 (WorldMap.vue)

**功能**：
- 加载 OpenStreetMap 底图
- 显示所有图钉标记
- 点击空白处显示搜索面板
- 点击图钉显示照片弹窗

**技术实现**：
```javascript
<template>
  <div class="world-map">
    <l-map
      :zoom="mapZoom"
      :center="mapCenter"
      @click="handleMapClick"
    >
      <l-tile-layer
        url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png"
      />
      
      <!-- 图钉标记 -->
      <l-marker
        v-for="marker in markers"
        :key="marker.id"
        :lat-lng="[marker.lat, marker.lng]"
        @click="showMarkerPhotos(marker)"
      >
        <l-icon-marker
          :icon-url="marker.icon"
          :icon-size="[40, 40]"
        />
      </l-marker>
    </l-map>
    
    <!-- 搜索面板（点击地图空白处显示） -->
    <SearchPanel
      v-if="showSearch"
      :position="clickPosition"
      @add-marker="addMarker"
      @close="showSearch = false"
    />
  </div>
</template>
```

### 2. 地点搜索面板 (SearchPanel.vue)

**功能**：
- 搜索框（OpenStreetMap Nominatim 搜索）
- 地点选择列表
- 图片上传（支持 jpeg/jpg/png）
- 确认创建图钉

**UI 设计**：
```

│  搜索地点          │
│  [输入框______] [搜索]  │

│  搜索结果          │
│  ○ 巴黎（法国）    │
│  ○ 东京（日本）      │
│  ○ 纽约（意大利）    │
│  ○ ...               │
├─────────────────────────┤
│  上传照片（支持多张） │
│  [选择文件] [上传]   │
```

**图片验证**：
```javascript

function validateImage(file) {

```

## 📊 安全注意事项

### 1. 本地存储限制
- 图片仅存储在本地 `src/assets/images/`
- 避免使用外部图床（需要 API key）
- 建议添加图片大小提示（虽然不限制）

### 2. XSS 防护
- 所有用户输入需要转义
- 图片文件名验证（防路径遍历）
- Vue 3 自动处理大部分 XSS

### 3. 文件上传验证
```javascript
// 严格的文件类型验证
const ALLOWED_TYPES = ['image/jpeg', 'image/jpg', 'image/png'];
const MAX_DISPLAY_SIZE = 50 * 1024 * 1024; // 50MB（仅显示提示）

function validateFile(file) {
  if (!ALLOWED_TYPES.includes(file.type)) {
    throw new Error('不支持的文件格式');
  }
  
  if (file.size > MAX_DISPLAY_SIZE) {
    alert(`文件较大：${(file.size / 1024 / 1024).toFixed(2)} MB，可能影响性能`);
  }
  
  return true;
}
```
